# 04 米国市場から翌営業日の日本市場への波及分析

## 中心仮説
米国市場の値動きが、その後に開場する日本市場の始値、場中、終値に先行的な説明力を持つ可能性を検証する。
因果関係を事前に固定せず、相関、先行性、予測力、再現性を評価する。

## 日本側の目的変数
- ギャップリターン = 当日始値 / 前営業日終値 - 1
- 場中リターン = 当日終値 / 当日始値 - 1
- 日次リターン = 当日終値 / 前営業日終値 - 1
- 始値から前場終値
- 後場始値から終値
- 高値・安値までの最大変動
- ギャップフィル有無
- 寄り付き方向と終値方向の一致

## 米国側の説明変数
- NASDAQ Composite
- NASDAQ 100
- Dow Jones
- S&P 500
- SOXまたは半導体関連指標
- VIX変化
- 米国10年債利回り変化
- USD/JPYの該当時間帯変化
- OHLCと終値位置
- 終盤リターン（取得可能な場合）
- 出来高・市場の広がり（取得可能な場合）
- セクターETF

## 時間整合
- UTCで保存し、取引所タイムゾーンとセッションIDを保持
- 米国セッション終了後、次に開く日本営業日へ対応
- 日米休日、連休、米国夏時間を考慮
- 日本休場中に複数米国セッションがある場合は、個別・累積双方を検討
- 同じカレンダー日付で単純結合しない
- 分析時点で利用可能な情報だけを使う

## 分析手法
- Pearson / Spearman相関
- 20/60/120/250営業日相関
- ローリング相関
- ラグ付き単回帰・重回帰
- ローリング回帰係数
- Granger因果性検定（予測上の先行性として説明）
- 条件別勝率
- イベントスタディ
- 相場局面別分析
- 業種・銘柄別感応度
- ウォークフォワード検証

## 条件区分
- +2%以上
- +1%以上+2%未満
- +0.5%以上+1%未満
- -0.5%超+0.5%未満
- -1%超-0.5%以下
- -2%超-1%以下
- -2%以下

各区分で、サンプル数、平均、中央値、方向一致率、ギャップ方向、場中継続・反転率、最大利益・損失、信頼区間を表示する。

## 対応例
- NASDAQ 100 / SOX -> 日本の成長株・半導体株・関連ETF
- 米国AI・データセンター・電力設備・銅関連 -> 日本のAIインフラ、電力・電化、銅テーマETF・関連株
- 米国防衛・宇宙関連 -> 日本の防衛・宇宙テーマETF・関連株
- 金・銀価格、実質金利、ドル指数 -> 日本の金・銀ETF。ただし価格連動ETFと鉱山・関連企業ETFを分離
- 米国ロボティクス・設備投資関連 -> 日本のロボティクス／FAテーマETF・関連株
- S&P 500 -> TOPIX・大型株
- Dow -> 日本の大型バリュー・輸出株
- 米国金融 -> 日本の銀行・保険
- 米国エネルギー -> 商社・資源
- USD/JPY -> 自動車・電機等の輸出関連

テーマと関連資産の正本は`docs/27_theme_sector_etf.md`とする。テーマごとに先行資産、ラグ、休日対応、重複・相関を版管理し、全テーマへ同じ係数を適用しない。J-Quants Freeの遅延研究では翌朝の現在予測として表示せず、`delayed_historical`の時点再現に限定する。

## 出力
- 翌朝の寄り付き方向の確率
- 想定ギャップレンジ
- 寄り付き後の続伸・反転確率
- 過去類似件数
- 業種別影響度
- 銘柄別感応度
- 対象期間、モデル版、更新時刻
- データ品質と不確実性

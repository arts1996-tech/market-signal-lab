# 仮想口座の投資判断ロジック

- 記録日: 2026-08-15
- 対象: 実データ仮想評価、デモ仮想口座、将来のニュース統合
- 位置づけ: 現行実装と将来方針を混同しないための正本

## 結論

現在の実データ仮想口座は、J-Quants Free planの約12週遅れ価格を使う過去検証である。最新ニュースを組み合わせて現在の買い判断をする機能ではない。

遅延価格と今日のニュースを混ぜると情報時点が一致しないため禁止する。過去検証では価格、ニュース、財務、米国市場情報を当時利用可能だった時点へそろえる。現在判断では、最新ニュースと同じ判断時点で利用可能な価格データが別途必要である。

2026-08-24に現物、信用買い、信用売り、自動選択を正式な将来要件へ追加した。現在の実データ口座と画面は引き続き現物買いのみであり、下落方向は`observe_only`である。MT-P3で信用買い・信用売りの保証金、費用、維持率、期限、強制決済を扱う合成研究用状態遷移コアまで追加したが、既存口座、DB、実provider、画面、モード別バックテストへは未接続である。MT-P4の統合が完了するまで、現行の実データ口座で信用建玉や信用売り利益を生成しない。詳細は[23 信用取引モード仕様](23_margin_trading.md)を参照する。

2026-08-25に、利用者が複数指定するティッカー集合だけを対象にする分析・仮想口座を将来要件へ追加した。分析は口座を変更せず、凍結済み分析スナップショットを利用者が明示開始したシミュレーションだけが使用する。詳細は[24 利用者指定ティッカー分析・仮想口座仕様](24_user_selected_ticker_simulation.md)を参照する。

同日に、市場の兆候を仮想口座で自動評価し、判断・見送り・取引結果をシステム内ナレッジとして継続更新する将来要件を追加した。自動実行は仮想口座に限定する。結果はまず観測・仮説として保存し、未見検証と利用者承認なしに稼働中のスコアやルールを変更しない。詳細は[25 シミュレーション振り返り・ナレッジ更新仕様](25_simulation_knowledge_feedback.md)を参照する。

## 現行の実データ判断

### 1. データ品質ゲート

- 日本株・ETFは東証カレンダー上で連続30営業日以上の有効な調整済みOHLCVを必要とする。
- 欠損や非連続期間をまたいで指標を計算しない。
- 始値、前営業日出来高、必要なOHLCがない場合は約定または決済判定を行わない。
- 非正値、無限値、OHLCの大小関係が不正な行を決済判定に使わない。

### 2. 日米市場コンテキスト

シグナル日より前のNASDAQ Composite、Dow Jones、S&P 500と日経平均を使い、20日・60日相関と直近の米国指数平均変動を計算する。現在の最新米国データを、12週前の日本株シグナルへ混ぜない。

### 3. 注目度スコア

基礎点40点へ次を加算し、0〜100に収める。

| 条件 | 加点 |
|---|---:|
| 日米平均相関の絶対値が0.45以上 | 15 |
| 日米平均相関の絶対値が0.25以上 | 8 |
| 米国指数平均の絶対変動が1%以上 | 10 |
| 米国指数平均の絶対変動が0.3%以上 | 5 |
| 20日ボラティリティが3.5%以上 | 18 |
| 20日ボラティリティが2%以上 | 10 |
| 5日騰落率の絶対値が5%以上 | 12 |
| 5日騰落率の絶対値が2.5%以上 | 6 |
| RSI 14が70以上または30以下 | 8 |
| 終値がボリンジャーバンド上限・下限付近 | 8 |

通常の仮想評価閾値は70点である。ただし、スコア70は上昇確率70%、勝率70%、期待収益を意味しない。統計的に未較正の注目度である。

### 4. 売買方向

- 正の相関があり米国指数平均が上昇した場合は、上方向候補とする。
- 米国指数平均が下落した場合は下方向候補とする。
- 下方向または方向未確定は`observe_only`とし、空売り利益を仮想口座へ計上しない。
- 仮想成績は参考統計として表示するが、候補スコアへ自動反映しない。

### 5. 仮想エントリーと数量

- 判断日の次の東証営業日の調整済み始値で買う。
- 製品要件は短期・中期それぞれ250万円で口座間の資金移動なしである。デモに加え、通常モード用の独立した継続口座状態、DBへの追記保存、再起動後の系統別復元まで対応した。`delayed_historical`と`current_market`は同じ口座・営業日でも別状態とし、J-Quants Freeの遅延価格は現在判断の鮮度ゲートを通過させない。将来結果を使う旧1口座は過去評価専用として分離して残す。
- 同時保有は2銘柄、1銘柄は初期資金の30%を上限とする。
- 1取引の計画損失は初期資金の1%、全保有の計画損失合計は5%を上限とする。
- エントリー価格と損切り価格の差から参考数量を逆算する。
- 前営業日出来高の10%を参加率上限とし、必要なら売買単位単位で部分約定する。
- 手数料0.10%、スプレッド0.10%、基本スリッページと参加率に応じた市場影響を加味する。税は`tax-accounting-pretax-v1`で税率0%の税引前評価に固定し、口座種別、源泉徴収、損益通算、繰越控除、申告税務を再現しない。非ゼロ税率は拒否し、将来の税モデルは仕様承認後に別バージョンで実装する。

### 6. 決済

- 現行通常モードの暫定条件は利益確定+8%、損切り-5%、最大保有1・5・10・20営業日から選択する。正式な短期・中期口座では口座別の条件と戦略版を固定する。
- 日次OHLCで利益確定、損切り、最大保有期限を判定する。
- 窓開けでは指値・逆指値水準ではなく始値で決済する。
- 同一日足で利益確定と損切りの両方へ到達した場合は、保守的に損切りを優先する。
- 入力にストップ安、取引停止等のフラグがある場合は、売却不能として次セッションへ繰り越す。

## ニュース利用の現在地

実データの候補抽出と仮想口座は、実ニュースをまだ使用していない。ニュースを使うのはデモモードだけで、すべて`demo_scenario`と明示した決定論的な合成ニュースである。

デモスコアは次の画面・計算確認用ルールであり、実市場の判断には使用しない。

```text
50
+ 5日モメンタム × 220
+ 20日平均乖離 × 160
+ 合成ニュース評価 × 12
```

## 将来の二系統

### 過去検証系統

- 12週遅れのJ-Quants価格を過去データとして使用する。
- その当時までに公表されていたニュース、財務、米国市場、為替、金利だけを組み合わせる。
- 公表時刻、取得時刻、利用可能時刻を保存し、先読みを防ぐ。
- 長期のアウト・オブ・サンプル検証とウォークフォワード検証に使用する。

### 現在判断系統

- 最新ニュースと同じ時点で利用可能な現在価格を使用する。
- 最新の米国市場、為替、金利、決算予定、適時開示を組み合わせる。
- データ鮮度、欠損、イベント前後、取引可能性をハードゲートにする。
- J-Quants Freeの遅延価格だけで1〜20営業日の現在エントリーを判断しない。

## 将来の判断フロー

```text
データ品質・時点整合ゲート
  -> 市場環境（日米指数・為替・金利）
  -> 価格・テクニカル
  -> 財務・業績
  -> ニュース・イベント
  -> 反対材料と不確実性
  -> Pythonによるスコア・価格水準・数量計算
  -> LLMによる説明と複数観点の整理
  -> 仮想口座で前向き記録
  -> 利用者が最終判断
```

このフローのPython判断では、`cash`、`margin_long`、`margin_short`を同じ判断時点で個別評価し、`auto_select`は適格なモードだけを比較する。信用可否、借株・逆日歩等の費用、返済期限、保証金・維持率が不足するモードは候補から除外し、現物へ暗黙フォールバックしない。短期・中期各250万円の既存口座内で必要保証金と建玉を管理し、信用取引用の別資金は作らない。

指定ティッカー経路では、このフローへ渡す投資可能集合を利用者が固定する。指定外銘柄を追加せず、集合版、分析入力、戦略版を凍結してから、指定集合専用の短期・中期口座を通常口座と別系列で動かす。J-Quants Freeの間は遅延研究に限定し、現在判断へ昇格させない。

Gemini、Claude、ChatGPT等を導入する場合も、価格、指標、数量、損益を計算させない。Pythonで計算・検証済みの構造化データだけを解釈させ、根拠、反対材料、不確実性を整理させる。LLM停止時もPython分析とStreamlitだけで縮退運転できるようにする。

## 運用境界

Mac定期ジョブは約12週遅れ価格による`delayed_historical`研究であり、現在価格による正式な前向き運用ではない。実投資判断へ利用するには、現在価格、ニュースの時点整合、長期未見検証、6〜12か月程度の前向き観察を必要とする。それまでは研究・検証・判断訓練に限定する。実装状態と残タスクは`docs/22_current_priority_todo.md`を正本とする。

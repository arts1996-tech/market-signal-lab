# 06 Slack連携仕様

## 目的
Slackを通知先だけでなく、利用者とGemini投資判断エージェントの主要な対話窓口にする。

## 技術
- Slack App
- Bolt for Python
- Socket Mode
- Web API
- Block Kit
- PostgreSQL

Raspberry Piを外部公開しないため、初期はSocket Modeを採用する。

## 初期機能
- `/market`
- `/analyze SYMBOL`
- BotへのDM・メンション
- スレッド内の追加質問
- 市場分析のBlock Kit表示
- 詳細をスレッドへ投稿
- 許可ユーザー・ワークスペース制御

## 将来機能
- `/entry SYMBOL`
- `/exit SYMBOL`
- `/screen ASSET_TYPE`
- `/portfolio`
- `/backtest SYMBOL`
- `/status`
- ボタン、メニュー、モーダル
- 保有銘柄の登録・更新・削除

## 定期投稿
- 米国市場終了後の日本市場オープン前レポート
- 日本市場終了後レポート
- 米国市場向けレポート
- 価格・損切り・決算・データ障害アラート

## 表示項目
- 市場環境
- 銘柄、現在値、データ時点
- 判断
- エントリー条件
- 利益確定候補
- 損切り候補
- リスクリワード
- 類似件数、過去勝率
- 根拠、リスク、品質警告

## 会話コンテキスト
毎回全履歴をGeminiへ送らない。
- 現在のスレッド
- 対象銘柄の直近分析
- 保有情報
- 過去会話要約
のみを必要に応じて利用する。

## 通知レベル
- INFO
- NOTICE
- WARNING
- CRITICAL

重複排除とクールダウンを実装する。

## セキュリティ
- トークンは `.env`
- ログへ秘密情報を出さない
- 許可ユーザー・ワークスペースのみ
- 入力銘柄・コマンドを検証
- Slack操作から任意コードを実行させない
- 発注機能を実装しない

# 08 Raspberry Pi運用

## 前提
- Raspberry Pi OS 64-bit
- Docker / Docker Compose
- ARM64対応イメージ
- DBデータは可能ならUSB SSDへ保存

## 定期処理例（JST）
- 06:30 米国市場データ取得
- 06:40 日米波及分析
- 07:00 日本市場オープン前Slackレポート
- 08:30 為替等の再確認
- 12:00 前場後更新（将来）
- 15:40 日本市場データ取得
- 16:00 テクニカル・統計分析
- 16:30 スコア・候補更新
- 23:00 DBバックアップ

市場休日と夏時間を考慮し、固定時刻だけに依存しない設計を目指す。

## 運用要件
- `restart: unless-stopped`
- ヘルスチェック
- 構造化ログ
- ログローテーション
- API再試行・タイムアウト
- ジョブの冪等性
- 失敗履歴
- ディスク空き容量監視
- DB容量監視
- データ鮮度監視
- Slackへの障害通知

## バックアップ
- `pg_dump`
- SSD等へ日次保存
- 保存期間を設定可能
- 古いバックアップを削除
- リストア手順をREADMEへ記載
- バックアップ成功・失敗を記録

## デプロイ
Macでテスト後、Git経由でRaspberry Piへ配置する。
`.env` と永続データはGit管理しない。

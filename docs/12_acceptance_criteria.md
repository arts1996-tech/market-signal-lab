# 12 受け入れ基準

## 共通
- Mac Apple SiliconとRaspberry Pi ARM64を想定
- `.env.example` がある
- 秘密情報がGitに含まれない
- `docker compose up -d --build` で起動可能
- READMEに起動・停止・ログ・テスト・バックアップ手順
- pytestが通る
- エラーが利用者に分かる
- データ時点と取得元を表示

## フェーズ1
- DBマイグレーションが成功
- 資産と日次OHLCVを保存可能
- 重複登録しない
- 米国市場セッションと次の日本営業日を対応可能
- 基本リターンと相関を計算
- Streamlitで指数比較と相関を表示
- 欠損・古いデータを警告

## フェーズ2
- ギャップ、場中、日次を分離
- 条件別統計にサンプル数を表示
- 休日・夏時間テスト
- 先読みなしのウォークフォワード検証
- 相関と因果を混同しない説明

## Gemini
- JSON Schemaに準拠
- データにない価格を生成しない
- 入出力と版を監査保存
- API停止時にPython結果を返す

## Slack
- Socket Mode接続
- 許可ユーザーのみ
- `/market` と `/analyze SYMBOL`
- Block Kit表示
- スレッド対話
- トークンをログへ出さない

## 投資判断
- 根拠と反対材料を併記
- エントリー、利益確定、損切り、無効条件を区別
- 過去類似件数と検証結果を表示
- 自動発注しない
- 最終判断が利用者にあることを表示

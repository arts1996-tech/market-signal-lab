## ポジションサイズ
許容損失額とエントリー・損切り価格の差から参考株数を計算する。
日本株の売買単位、米国株の通貨、保有上限、集中リスクを考慮する。
最終投資額は利用者が決定する。

## 将来の仮想ポートフォリオ・シミュレーション要件（フェーズ4で実装）

実注文は行わず、判断カードに基づく仮想的な売買を記録して、資産残高の増減を検証する。

- 短期売買用と中期売買用を完全に分け、それぞれ**250万円（JPY）**の初期資金から開始する。
- 仮想エントリー、保有、利益確定、損切りを取引として記録する。
- 各取引について、時点、銘柄、売買方向、約定仮定、数量、エントリー理由、利益確定・損切り理由、実現損益、未実現損益を残す。
- 短期・中期ごとに、現金、評価額、実現損益、未実現損益、累積損益、最大ドローダウン、残高推移を表示する。
- 両口座間の資金移動は、将来の明示的な仕様追加まで行わない。
- 手数料、スプレッド、税金、約定価格、為替コスト、売買単位、同時保有上限、欠損時の約定不可ルールは実装時に確定し、バックテストと同じ前提を記録する。
- 実取引・自動発注・利益保証には使用しない。結果は過去の仮定に基づくシミュレーションとして表示する。

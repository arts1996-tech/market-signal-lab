# 09 セキュリティ・品質

## 秘密情報
- `.env` 管理
- `.env.example` は値を空にする
- Git除外
- ログへ出力しない
- 定期的にローテーション可能にする

## ネットワーク
- StreamlitとPostgreSQLを無制限にインターネット公開しない
- 外部アクセスはTailscale等を想定
- PostgreSQLは内部ネットワーク中心
- SlackはSocket Mode

## 入力安全
- 銘柄コード、期間、パラメータを検証
- SQLAlchemyの安全なクエリを利用
- 任意SQL・任意コード実行を許可しない
- LLMのツール引数も再検証

## テスト
- リターン、RSI、MACD、ATR
- 相関、ローリング相関、回帰
- 米国セッションと次の日本営業日の対応
- 日米休日、連休、夏時間
- 条件別集計
- Granger検定の入力条件
- 重複登録防止
- API再試行
- バックテストの先読み防止
- 円建てリターン
- Slackコマンド解析
- 認可
- Block Kit
- 通知重複排除
- Gemini障害時フォールバック

## 投資分析品質
- ウォークフォワード検証
- 学習・検証期間を分離
- 手数料、スプレッド、為替コストを設定可能
- サンプル数と信頼区間を表示
- 過学習を警告
- ルール・モデル版を保存
- データ欠損や改訂を記録
